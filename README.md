# Interactive Periodic Table / 互動週期表

118 元素互動週期表，內建分子量計算、反應式守恆驗證與元素小測驗。中英雙語。

Single-file HTML demo using React via CDN. No build step required.

## Run

```bash
# Open directly in browser
open index.html

# or serve via simple HTTP server
python3 -m http.server 8000
# then visit http://localhost:8000/
```

## Stack

- React 18.2.0 (UMD via unpkg)
- Babel Standalone 7.24.5 (for JSX in-browser transform)
- Pure HTML/CSS, no bundler
